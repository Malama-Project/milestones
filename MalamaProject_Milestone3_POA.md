1. Beta Version of The Malama Project Platform
a. Usable Website for Community Members to Test
The beta platform is now publicly live and fully functional:
https://app.malamaproject.org

This release incorporates user feedback and introduces tools that directly support regenerative land practices. Platform capabilities include:

Selection of land parcels via TMK or interactive mapping.

Creation of Efforts (e.g., Soil Testing, Biochar Creation, Biochar Application, Micro-Piling).

On-chain minting of efforts using CIP-68 compliant NFTs.

Real-time display of effort metadata via the interactive map.

Transaction hash notifications after each mint.

User profiles link directly to CardanoScan for on-chain verification.

✅ Specific Reviewer Updates Incorporated:
We’ve made several important updates based on the feedback received:

Segmenter: Replaced with an easier, point-by-point input model based on user testing. Full explanation.

Effort Types: Biochar Creation was the initial focus. We’ve now re-added “Soil Test” and introduced a new method, “Micro-Piling,” to demonstrate upcoming flexibility.

Testing Feedback: Created formal issues with acknowledgments of farmer-recommended changes, including a structured sign-off process.
📝 Sign-off Issue

NFT Proof: Minting is live. Users can view transaction hashes directly from their profile. An image demonstrating this live explorer link is included: Explorer Link Example.

CIP-68: This was always the intended standard—our report originally labeled it as “Plutus Datum Integration.” The label has been corrected to reflect actual implementation clearly as “Plutus Datum Integration / CIP-68 Implementation.”
